# PocketAI for iPhone

SwiftUI iPhone app: on-device chat, model management, and pairing with a Mac host. Shared code lives in `PocketAI.Core/swift` (`PocketKit`, `PocketUI`, `PocketMLX`), consumed as a local sibling Swift package. Design spec and task cards live in the sibling `strategy/` directory; see `strategy/05-tasks-apple.md` §L5.
